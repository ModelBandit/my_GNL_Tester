# My GNL Tester

A simple tester for the 42 **get_next_line** project.
This tester not working bonus.

## Usage

1. Place this tester inside your `get_next_line` directory.
2. Open a terminal in the tester directory.
3. Run the following command:

   ```bash
   make
   ```

## Configuration

If your directory structure is different, modify the directory paths in the `Makefile` accordingly.

## Notes

Make sure your GNL source files are in the expected directory before running the tester.
